# Custom host character

The video shows a host who talks, leans on cards and points at screenshots. The covers show the same character. The repo ships only a **neutral placeholder silhouette** in `assets/host/placeholder/`.

## Rights first

Only use artwork that you drew yourself, that you own, or that you have a license for, including commercial use if your channel earns money. Characters from games, anime, films or other people's art are usually protected by copyright and trademark. Publishing videos with them can get the videos removed or the account penalized. That risk is yours.

## Steps

1. Make a folder, e.g. `assets/host/my-host/`. Keep it out of git if the artwork is private, by adding it to `.gitignore`.
2. Put PNG files with a transparent background in it, named exactly as below.
3. In `config.local.json` (or `config.json`):
   ```json
   {"host": {"name": "Your host's name", "dir": "assets/host/my-host"}}
   ```
4. Run an episode or `npm run studio`. The images are copied to `public/host/` before each render.

## Files

Sizes are what the layout was tuned for. Similar proportions work; the character should stand at the bottom edge of the image.

| File | Size (px) | Pose |
|---|---|---|
| `idle-0.png`, `idle-1.png`, `idle-2.png` | 605 × 1000 | Standing, talking: mouth closed / half open / open |
| `idle-b.png` | 605 × 1000 | Standing, eyes closed (blink) |
| `present-0/1/2/b.png` | 627 × 1000 | Presenting with open hands (same four mouth/blink frames) |
| `lean-0/1/2/b.png` | 787 × 900 | Leaning in from the side to "hold" a card (same four frames) |
| `point.png` | 662 × 1000 | Pointing at the screen |
| `thumbs.png` | 593 × 1000 | Thumbs up (end card) |
| `side.png` | 637 × 1000 | Side pose |
| `avatar.png` | 320 × 320 | Round avatar for the header bar |
| `cover-point.png` | 720 × 1076 | Cover: pointing |
| `cover-open.png` | 720 × 1135 | Cover: open hands |
| `cover-thumb.png` | 720 × 1196 | Cover: thumbs up |

Mouth frames are switched 15 times per second from the voice-over loudness. They only need to differ around the mouth. A blink is inserted every few seconds.

For covers, a white outline around the character looks best. Bake it into the PNG, because CSS `drop-shadow` on transparent images renders as a pale box in headless Chrome.

The placeholder set is generated by `node scripts/make-placeholder-host.mjs`; you can use that script as a template.
